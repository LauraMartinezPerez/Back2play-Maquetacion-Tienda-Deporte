# 🏫🎽 Maquetación Responsive de Tienda Deportiva Infantil – Proyecto Back2Play

Este es mi **primer proyecto web** como programadora fullstack. Se trata de la **maquetación de una tienda online especializada en material deportivo infantil**, pensada para la temporada de **vuelta al cole**.

Aunque es una **one-page**, está diseñada con enfoque profesional: es totalmente **responsive**, está organizada con buenas prácticas en SASS, y se ejecuta con entorno Node.js.

## 🚀 Tecnologías usadas

- 🧱 HTML5
- 🎨 SASS (preprocesador CSS)
- ⚙️ Node.js + npm scripts (`npm run dev`)
